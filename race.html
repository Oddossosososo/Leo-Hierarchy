Interactive experiment · 07 / Race lab

Set the starting fuel.

Give every Leo its own n, then choose which Leo's output becomes its input. Any tier can feed another tier, so you can build chains and compare the resulting expressions.

How this works: Each lane has a starting n and an input source. “Its own n” uses that lane's number. Choosing another Leo means that function's output is passed in as this lane's input. Cycles are detected and flagged.

Race results

Set your inputs, then run the race setup.

Math status: This lab displays exact symbolic input chains. It does not invent numerical outputs: the complete executable definitions and evaluation rules for all eight Leo functions are not yet specified. The official tier order is shown as the project's declared order, not a proven same-input numerical race result.
